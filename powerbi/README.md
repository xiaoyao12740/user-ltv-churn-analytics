# Power BI setup

Load the CSV files from `data/processed`: `monthly_kpis.csv`, `daily_kpis.csv`, `cohort_retention.csv`, `powerbi_users.csv`, `powerbi_customer_features.csv`, and `customer_segments.csv`. Use Power Query folder parameters so paths remain portable. Create relationships on `user_id`, add a calendar table, then implement the measures in `dax_measures.md`. The `.pbix` is intentionally not generated by Python; export the finished report screenshot as `reports/figures/11_powerbi_dashboard.png`.
