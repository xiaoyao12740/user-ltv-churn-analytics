# Dashboard design

1. **Executive Overview** — KPI cards for Users, MAU, DAU/MAU, Revenue, ARPU, Churn Rate, Avg LTV; monthly trend line and channel slicer.
2. **Retention** — D1/D7/D30 cards, cohort heatmap, retention by channel and device.
3. **Customer Value** — LTV histogram, LTV by channel, value segment counts, actual versus predicted scatter.
4. **Churn Risk** — high-risk count, probability histogram, Value × Risk scatter, drillable high-risk customer table with recommended action.

Use a 16:9 canvas, accessible blue/orange palette, consistent date and currency formats, and tooltips that disclose the synthetic-data scope.
